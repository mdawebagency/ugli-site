# «Угли» — концепт нового сайта

Демо-версия нового сайта для мясного ресторана «Угли» (Екатеринбург) — подготовлена как предложение по редизайну ugli-ekb.ru.

Все тексты, фото, меню, новости и контакты взяты с действующего сайта ресторана; новые — только дизайн, вёрстка и анимации.

**Это демо:** формы брони, подписки и обратной связи пока не отправляют данные — их подключают к системам ресторана при запуске. Сайт закрыт от индексации поисковиками.

## Что внутри

- `index.html` — главная: первый экран с видео, «О ресторане», новости и акции, подписка, меню, вопросы, связь с руководством, контакты
- `menu.html` — полное меню (464 позиции в 27 разделах) и меню в PDF
- `news.html` — все новости и акции, банкетный зал
- RU / EN, адаптив под телефон, анимации на Motion и anime.js
- `tools/` — скрипты, которыми собраны меню, новости и вопросы с сайта ресторана

## Локальный запуск

```bash
ruby serve.rb
```

Затем открыть http://localhost:5173
